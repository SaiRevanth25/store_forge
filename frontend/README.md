
# Store Forge

Store Forge is an e-commerce store provisioning and management platform. This is the frontend React application for managing store deployments.

## Features

- User authentication (signup/login)
- Create and manage multiple e-commerce stores
- Real-time provisioning status tracking
- Direct access to store dashboards
- Store event monitoring

## Prerequisites

- Node.js 18+
- pnpm, npm, or yarn

## Installation

Run `pnpm install` to install the dependencies.

## Development

Run `pnpm dev` to start the development server.

The development server will start at http://localhost:5173

## Build

Run `pnpm build` to create an optimized production build.
